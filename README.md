# THAL3S 16

## A confident answer should earn your trust.

A number can look precise while its evidence is incomplete. An AI explanation can
sound convincing while getting a fact wrong.

We’re building THAL3S 16 around one conviction: **uncertainty belongs in the answer,
not hidden behind it.** This public project window shares the problem, a small
independently authored synthetic example, and a place to challenge our assumptions.
The financial intelligence engine remains private.

### Try the moment that matters

```sh
python example.py
python -m unittest discover -s tests -v
```

No account, credentials, installation or network needed. The generic example
rejects a wrong amount even though it cites the correct source token. It does not
implement THAL3S valuation, credit policy, evidence-grounding or replay algorithms.

Open [presentation.html](presentation.html) locally for six keyboard-navigable
screens. Nothing is hosted; the page uses no remote resources or inference.

## Six stages, one honest story

1. **Ask the question:** what evidence supports the answer?
2. **See disagreement:** two fictional estimates need review.
3. **Keep review explicit:** an illustrative result is not credit approval.
4. **Challenge the explanation:** a valid source token cannot rescue a wrong fact.
5. **Reopen the record:** saved-scene playback is not fresh model generation.
6. **State the limits:** model explains; deterministic code decides.

These are separate illustrative scenes, not a connected financial pipeline. Every
example is invented; model-shaped responses are **SCRIPTED**, not live generations.
