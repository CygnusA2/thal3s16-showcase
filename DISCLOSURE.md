# What this showcase discloses

This public surface consists of a newly authored story, static presentation,
trivial fictional-fact checker, its four tests and offline CI. All sample amounts
and tokens are invented for the showcase. No original private code, history,
engine thresholds, formulas, fixtures, source identifiers or internal URLs appear.
The checker only compares four supplied values with one fictional record; it is
not the private financial system's evidence-grounding or replay implementation.
Recorded playback in the slides means scripted-scene playback, not live inference.

## Separate Meta example: future design only

The runnable example has no model client, API key lookup or live switch. A future
separately authorized experiment could send ONLY its invented four-field fact to
Meta Standard `muse-spark-1.3` at `https://api.meta.ai/v1/chat/completions`, using a
strict JSON-schema response format and an independent exact-value/source check.
No private engine, source or policy would be sent. That request is not implemented
or performed here; account, credits, bounded cost/request count and exposure
approval must precede any actual call. No automatic retries or Contributor model
substitution. Standard mode's training distinction is not an NDA.

Official references consulted as documentation only:

- https://dev.meta.ai/docs/quickstart
- https://dev.meta.ai/docs/models
- https://dev.meta.ai/docs/structured-output

No cookbook code, SDK, model weights or third-party assets were copied. The private
prototype's 96 offline tests and this repository's four checks are separate evidence
sets. Current live Muse Spark structured-contract compliance is not demonstrated.
No API requests, credentials, financial transactions, real provider/client records,
private screenshots or videos are used here.

This project window is not an official entry submission, legal/eligibility
clearance, production-readiness statement, real appraisal or approval of credit.
Publishing this independent surface does not release the private engine. No
open-source license is selected; source visibility alone is not a license grant.
